PUBLICAR EN GITHUB PAGES
1. Crea un repositorio PUBLICO llamado spanish-con-nativos (o el nombre que prefieras).
2. En Add file > Upload files, sube el CONTENIDO de este ZIP, no el ZIP cerrado. Conserva la carpeta assets.
3. Commit changes.
4. En Settings > Pages, elige Deploy from a branch, branch main, folder /(root), y Save.
5. Espera unos minutos y abre la URL que GitHub indique.

index.html es la portada en español; index-en.html es la página en inglés.
Antes de publicar confirma que tienes permiso para mostrar nombres y fotografías de estudiantes.
